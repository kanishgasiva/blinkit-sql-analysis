# Blinkit Sales Analysis

Project Overview
--

Analyzed Blinkit sales data using SQL to understand product performance, outlet performance, pricing, visibility, and sales trends

Dataset 
--
Source: Kaggle

Link: https://kaggle.com/datasets/mukeshgadri/blinkit-dataset

Contains restaurant-level information including location, ratings, votes, cuisines, cost, and other restaurant attributes.

Objective
--

To identify key sales patterns and business insights across products and outlet characteristics

Project Workflow
--

1. Download the dataset and analyze the data in SQL
2. Perform data preparation and cleaning
3. Calculate key performance indicators (KPIs)
4. Perform exploratory sales analysis
5. Analyze outlet and product performance
6. Answer business questions using SQL
7. Identify key insights from the analysis

KPIs
--

* **Total Sales** — Overall revenue generated
* **Average Sales** — Average sales per item record
* **Number of Items** — Total sales records in the dataset

Analysis
--

* **Sales by Fat Content** — Compares revenue contribution across product fat categories
* **Sales by Item Type** — Identifies top-performing product categories
* **Fat Content by Outlet Location** — Compares sales across product categories and outlet locations
* **Sales by Outlet Establishment** — Examines sales performance across outlet establishment years
* **Fat Content Distribution** — Compares product volume across outlet locations
* **Sales by Outlet Location** — Evaluates revenue, average sales, and item volume
* **Outlet Type Performance** — Compares outlet types using sales, visibility, and item volume

Business Questions
--

* Which item categories generate the highest sales within different price ranges?
* Which outlet type and location combination performs best?
* Which products have high visibility but relatively low sales?
* Which item types perform best within each outlet type?
* Which outlet types have the highest average sales per item?
* How does outlet age relate to sales performance?
* What percentage of total sales comes from each item category?

Key Insights
--

* Identified the highest-performing product categories and outlet types.
* Compared sales performance across different price segments and outlet locations.
* Identified products with high visibility but below-average sales.
* Examined the relationship between outlet establishment year and sales performance.
* Determined the contribution of each product category to overall sales.
